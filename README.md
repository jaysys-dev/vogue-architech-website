# Vogue Architech Website

## Purpose

The website repository for Vogue Architech.

## Technology

- Astro with standard JavaScript
- Plain CSS

## Current scope

The project contains a minimal working shell for the future homepage. No other pages or homepage design have been added.

## Structure

- `public/` — static fonts, images, and video assets
- `src/components/` — reusable Astro components
- `src/layouts/` — shared page layouts
- `src/pages/` — file-based pages; currently only the homepage
- `src/scripts/` — browser-side JavaScript
- `src/styles/` — shared CSS files

## Commands

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```
